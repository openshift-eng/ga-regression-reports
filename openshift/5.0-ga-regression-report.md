# OpenShift 5.0 GA Regression Report

## Summary

Author: dgoodwin

Positives: 23% increase in jobs covered by component readiness is a huge gain, while our total unique bugs dropped 4%. This is a possible indicator that our ability to deliver code without regressing is improving as we increasingly leverage AI in our work. 

Time to triage is up significantly but still within reasonable values. QSE is on the brink of automating the board triage progress, agent is currently shut down while we fine tune it but was operational for part of 5.0. It was extremely good at triaging regressions to existing bugs/triage records, but struggled with opening coherent bugs. In 5.1 we expect to have this operational again with human approval before opening new bugs, and better guidance on how to file a solid bug.

Issues requiring SBAR remain effectively flat, our weak point continues to be non-customer facing test-only problems we lose focus on, and fixes upstream that take longer to get through.
